🧱 Tiles Gallery – Next.js E-commerce Project

A modern, responsive tile product showcase & details web app built with Next.js, Tailwind CSS, and dynamic JSON data.

🚀 Live Features
🏠 Product listing page (All Tiles)
🧾 Dynamic product details page
⭐ Star rating system (React Icons)
📦 Stock availability system
🖼 Optimized product images (Next.js Image)
🎨 Modern UI with Tailwind CSS
⚡ Fast performance (Next.js App Router)
🛠 Tech Stack
⚛️ Next.js (App Router)
🎨 Tailwind CSS
🧠 JavaScript (ES6+)
🖼 Next.js Image Optimization
⭐ React Icons

✨ Key Features
🖼 Product Details Page
Dynamic routing 
Beautiful image showcase
Hover zoom effect
⭐ Rating System
Star-based rating using react-icons
Dynamic rendering (0–5 stars)
📦 Product Info
Material, category, dimensions
Stock availability status
💰 Pricing Section
Dynamic price display
Disabled button when out of stock
